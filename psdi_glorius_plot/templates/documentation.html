Advanced Use

This service functions as a Flask application. If you'd like to run it locally, you can clone the repository from the “Project source” link below and follow the instructions in README.md to install it (Python 3.11 required). This will allow you to run it without worrying about downtime, run an old version if a feature you are using is removed, or fork and modify it to your preference.
